# Project Plan

## Goal

Make Dimes feel as easy as maintaining the existing spreadsheet, while using Supabase as the durable backend.

## Phases

1. Supabase foundation
2. Spreadsheet-style Monthly Summary and Ledger
3. Import current spreadsheet data into Supabase tables
4. Add transaction, monthly plan, balance, and category editing
5. Add richer features only after the basics feel better than the spreadsheet
